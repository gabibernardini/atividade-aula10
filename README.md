# 📌 Sobre o projeto

Este trabalho apresenta o portal de notícias TechNews Today, um projeto moderno desenvolvido para demonstrar o uso de HTML semântico combinado com técnicas avançadas de CSS para estilização e layout responsivo.

# 🎯 Objetivo do projeto

O objetivo é criar uma página web funcional e atraente utilizando recursos modernos de CSS, como Glassmorphism, CSS Grid, Gradientes de texto e Media Queries, garantindo uma boa visualização tanto em desktop quanto em dispositivos móveis.

# 🎨 Elementos apresentados

O projeto contém:

-Header fixo (sticky) com efeito de vidro fosco (Glassmorphism) e logo com texto em gradiente;

-Artigo em destaque sobre IA com detalhes expansíveis (<details> / <summary>);

-Seção de vídeo incorporado (<iframe>) com integração do YouTube;

-Formulário de Newsletter responsivo com seletores, caixa de seleção e botões estilizados;

-Layout responsivo em Grid que ajusta a distribuição do conteúdo conforme a tela.

# 🛠️ Ferramentas e Tecnologias utilizadas

O projeto foi desenvolvido utilizando:

-HTML5;

-CSS;

-VS Code.
