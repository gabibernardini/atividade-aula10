# 📌 Sobre o projeto

Este trabalho apresenta o portal moderno de notícias de tecnologia TechNews Today. O projeto foi desenvolvido com foco na estruturação semântica em HTML5 e estilização avançada em CSS3, incluindo efeitos visuais modernos como *glassmorphism*, gradientes e layout responsivo com CSS Grid[cite: 3, 4, 5].

# 🎯 Objetivo do projeto

O objetivo é criar um portal de notícias web moderno, interativo e totalmente responsivo[cite: 3, 4, 5], utilizando recursos avançados de CSS3 sem o uso de frameworks ou JavaScript[cite: 5], garantindo a aplicação correta de conceitos de design e usabilidade[cite: 3, 4, 5].

# 🎨 Elementos apresentados

O projeto contém:
- **Cabeçalho Fixo com Glassmorphism:** Efeito de vidro fosco (`backdrop-filter`) e título estilizado com gradiente no texto[cite: 3, 5];
- **Artigo em Destaque:** Card estilizado com suporte a expansão de texto (`<details>` / `<summary>`)[cite: 3, 4];
- **Seção de Vídeo:** Incorporação de vídeo (`<iframe>`) centralizado com borda personalizada[cite: 3, 4, 5];
- **Formulário de Newsletter:** Campos de texto, seleção (*select*), *checkbox* de termos e botão de inscrição com animação e gradiente[cite: 3, 4];
- **Layout Responsivo (CSS Grid & Media Queries):** Organização das seções lado a lado em telas maiores e adaptação fluida para dispositivos móveis[cite: 3, 5].
